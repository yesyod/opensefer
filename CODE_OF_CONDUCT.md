# Code of Conduct

## Our pledge

OpenSefer is an open, welcoming community for everyone, regardless of background or identity.
Contributors and maintainers pledge to make participation a respectful, harassment‑free experience
for all.

## Our standard

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its Code of Conduct. In short: be respectful and considerate, assume good faith, welcome
newcomers, and accept constructive feedback gracefully. Conduct that harasses, demeans, or excludes
others is not acceptable.

Please read the full text — it defines expected and unacceptable behaviour, the scope, and the
enforcement guidelines in detail:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Scope

This Code of Conduct applies within all project spaces — the repository, issues, pull requests, and
discussions — and whenever an individual is representing the project in public.

## Enforcement

Report unacceptable behaviour privately to the project maintainers via the repository owner's
[GitHub profile](https://github.com/yesyod). All reports will be reviewed and investigated promptly
and fairly, and the reporter's privacy will be respected.
Maintainers are obligated to enforce this Code of Conduct in good faith; those who do not may face
temporary or permanent repercussions as determined by the project's leadership.
